# Fonts

The Macintosh screen uses two pixel fonts by Giles Booth, both published under a Creative
Commons Attribution licence:

- `ChiKareGo2.woff2`: ChiKareGo2, a recreation of Chicago 12.
  https://www.pentacom.jp/pentacom/bitfontmaker2/gallery/?id=3780
- `FindersKeepers.woff2`: FindersKeepers, a recreation of the Finder's Geneva 9.
  https://www.pentacom.jp/pentacom/bitfontmaker2/gallery/?id=3809

Changes made for this game: ChiKareGo2's letter spacing is one pixel instead of two, the word
space is narrower in both (four pixels and three), the vertical metrics are whole pixels, a
trademark sign is added, curly quotes are mapped to the straight ones, and the files are converted to WOFF2.

One font pixel is 1/16 of the em, so both are meant to be set at 16px (or a whole multiple).
