# Lockdown

A browser game. You are locked in a subglacial station with five minutes on the clock, and the way
out is somewhere on a file system you fly through in 3D, on a desktop modelled on SGI's IRIX.

```
npm install
npm run dev
```

`npm run build` writes a static site to `build/`. Version history is in [CHANGELOG.md](CHANGELOG.md).
